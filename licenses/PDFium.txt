PDFium
======

OrbitConvert bundles pdfium.dll, a binary build of Google's PDFium library produced by the
"pdfium-binaries" project (https://github.com/bblanchon/pdfium-binaries) and distributed through the
bblanchon.PDFium.Win32 NuGet package (declared license: Apache-2.0).

PDFium source code: https://pdfium.googlesource.com/pdfium/
PDFium's own LICENSE file contains the BSD-3-Clause license below for code by The PDFium Authors,
followed by the Apache License 2.0 for code contributed by Foxit Software. PDFium also incorporates
third-party libraries (among them FreeType, libjpeg-turbo, Little CMS, OpenJPEG, libpng, zlib and
Abseil), each under its own permissive license as listed in PDFium's third_party directory. Refer to
the upstream repository for the complete, authoritative texts.
